# Garage System

A comprehensive garage system for FiveM servers with vehicle storage and retrieval.

## Features

- Multiple garage locations with configurable coordinates
- Vehicle storage and retrieval system
- Integration with ESX framework
- Configurable marker types and colors

## Requirements

- FiveM server
- ESX framework
- MySQL database

## Installation

1. Download the script files
2. Place them in your FiveM server resources folder
3. Add `start garage-system` to your server.cfg
4. Import the database.sql file into your MySQL database

## Usage

1. Players can access garages by approaching the marked locations
2. Use the menu to store or retrieve vehicles
3. Configure garages in the config.lua file

## Configuration

Edit the `config.lua` file to:
- Add or remove garages
- Set garage coordinates and spawn points
- Configure marker appearance
